# Playground

A small demo site for developing the CMS. Its content is placeholder text.

```bash
npm install
npm run dev
```

Run both from the repository root: `dev` builds the package, then starts this
site. The dashboard is at http://localhost:4321/admin (no login unless
`CMS_PASSWORD` is set in `.dev.vars`). Publishing writes the JSON files here;
nothing is committed or pushed.
